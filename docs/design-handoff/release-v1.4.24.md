# v1.4.24 · 界面主题统一与托盘入口优化

本次发布合入此前的 Codex MSIX 下载器、嵌入式分析面板，并完成新设计的首轮视觉改造。

- 七套主题共用面板颜色：彩字浅白、橙色暖白、原生灰白；不透明背景、细边框、常规字重。
- 设置、分析、嵌入下载面板统一目标宽度，菜单跟随主题，下载面板右侧锚定。
- 新蓝色 `>_` 托盘图形，左键打开完整版下载器，右键保留退出。
- 切换面板撤销未保存设置，保留现有配置与下载/安装机制。

安装：运行附件 Setup EXE，可覆盖旧版，保留配置。SHA256SUMS.txt 用于校验安装包。

验证：C# 构建和现有回归测试通过；附件截图由程序离线绘制，使用演示数据，不是实际账户数据。100%–200% 实机跨屏验收尚未完成。

已知限制：本地分析去重与指标口径仍需修正，不等同于官方分析；多 Tab 完整版下载器、共享下载任务、多状态托盘尚未完成。本次不会接入虚构分析数据。
