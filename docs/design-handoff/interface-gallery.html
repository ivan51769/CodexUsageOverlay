现有程序是 C# WinForms 桌面程序，没有现成的 HTTP 前端接口。下面分清已核实的数据来源与建议的界面交互约定；不要让设计者把建议的方法名当成已实现 API。

补充核验：本机协议快照中的 account/usage/read 定义了可为空的 dailyUsageBuckets（startDate、tokens），以及连续使用天数、单日峰值等 summary 字段；当前程序只消费累计 Token。每日趋势具备协议接入线索，但实际返回与覆盖日期尚未验证。原生分析按产品、模型和工具的明细接口仍未确认。

请设计者一起交付什么？

请提供：完整 HTML/CSS/JS、统一颜色/边界/字号/间距变量、所有面板及悬浮/按下/选中/禁用状态、100%–200% 缩放适配规则、图标 SVG、示例数据结构、界面动作与数据事件清单，以及空数据/过期/错误/下载中等状态。无需编造官方接口或提供账号密钥。

建议桥接动作（待实现）：refreshUsageAndRadar、loadAnalytics(period)、previewSettings、saveSettings、cancelSettings、checkCodexVersion、downloadMsix、installMsix、cancelDownload、openFullDownloader、checkAssistantUpdate、closePanel、exitApp。

建议事件（待实现）：usageChanged、radarChanged、analyticsLoaded、downloadProgress、operationFailed、settingsChanged、hostBoundsChanged。每条数据带来源、更新时间和是否过期；获取不到显示“暂无数据”，不能填 0。

必须保留的使用要求

所有文字用微软雅黑；默认顶部、单行、小圆角、彩字。原生主题用原生灰色文字与细线无框图标；四个按钮依次刷新、设置、分析、下载，同尺寸同中轴，悬浮可见，线条不加粗。设置/分析/下载面板共用主题及宽度；聊天框内/下方向上展开。展开面板不透明；公众号和作者名称保持紫色七彩渐变。菜单点外部或 Esc 关闭；托盘下载器为独立完整版，Codex 退出后仍可用。按钮文字固定单行完整显示，高 DPI 不重叠不裁切。两行胶囊按内容收窄，所有数值和日期不自动省略。

源码默认字号：顶部 12 pt（6–18），框内及框下 7.2 pt（6–9）；HTML 为可读位置示意，不模拟 GDI/DPI 的像素误差。重新设计应给出 DIP/pt/px 换算和实机验收要求。
