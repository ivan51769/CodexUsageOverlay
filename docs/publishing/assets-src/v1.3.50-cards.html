Codex Usage Overlay版本简报 · 03
04

BOUNDARY

只负责显示，不创造额度

非官方

这是一个 Windows 辅助工具。它把本机 Codex 返回的信息放到更容易看到的位置，边界仍然要说清楚。

它会做

  • 读取本机 Codex 返回的用量
  • 提供三种显示位置
  • 显示公开非官方重置信号
  • 检查 GitHub 稳定版更新

它不会做

  • 不会增加或强制重置额度
  • 不会代表 OpenAI 官方承诺
  • 不会读写 auth.json
  • 不会保存对话正文

感谢猫de天空之城、乐缘、谢谢你提醒我，提供问题定位、修复建议与验证。
