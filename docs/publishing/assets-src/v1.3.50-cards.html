04 / 04

它会做

  • 读取本机 Codex 返回的用量
  • 让你选择三种显示位置
  • 显示公开非官方的重置信号
  • 检查 GitHub 稳定版更新

它不会做

  • 不会增加或强制重置额度
  • 不会代表 OpenAI 官方承诺
  • 不会读写 auth.json
  • 不会保存对话正文

Tibo Radar 是公开、非官方信号。实际额度始终以本机 Codex 返回结果为准；每个账户的到账时间也可能不同。
