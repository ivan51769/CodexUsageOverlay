## 摘要

v1.3.50 把 Codex Usage Overlay 的显示位置、用量排版和胶囊风格改为直接选择；无胶囊模式也补了浅色标题栏的文字对比。工具只读取和展示本机 Codex 返回的数据，不会增加或主动重置额度。

## 正文

写 Codex 时，最烦的有时不是功能少，而是设置要靠“点一下看看”。

悬浮条到底放顶部、放对话框里，还是贴在输入框下面？一行看完还是拆成两行？圆角、小圆角、无胶囊，原来都需要来回切换才能确认结果。

这次 v1.3.50，我把这三处统一改成了**看见选项，直接点选**。

[图1：v1.3.50 设置界面真实截图，三个显示位置并列直选]

## 这次改的不是“多一个开关”

**显示位置**　顶部任务栏、聊天对话框内、聊天对话框下面，三个按钮并列展示，当前选择会高亮。切换后不会覆盖到另一个位置。

**用量排版**　一行概览适合顶部任务栏；两行详情适合输入框附近。需要时把 5H、周额度、重置券和累计 Token 拆开看，不需要再靠猜测切换结果。

**胶囊风格**　圆角、小圆角矩形、无胶囊三个样式同样直接选择。设置面板与悬浮设置页保持相同的交互，不用记住“再点一次会切到哪里”。

[图2：一行概览、两行详情和三项直接选择的说明图]

## 无胶囊，不等于看不清

这轮也修了一个很实际的问题：在浅色标题栏里，无胶囊文字以前可能显得太淡。

现在无胶囊模式会使用跟随主题但保持足够对比的文字颜色；套餐、额度、雷达状态、刷新与设置按钮都应该清楚可辨。这里的主题只影响显示，不会改变本机读取的额度、重置时间或累计 Token。

[图3：渐变彩字、荧光蓝和无胶囊模式的真实界面截图]

## 它能做什么，不能做什么

这仍然是一个非官方 Windows 辅助工具。

账户套餐、额度、重置时间、重置券和累计 Token 通过本机 Codex 的 app-server 获取；工具不会直接读写 `auth.json`，不会保存对话正文，也不会把本机额度上传给 Tibo Radar。

**Tibo Radar 只读取公开的非官方状态信号。**它可以提示“今日已重置”“有预告”或“暂无信号”，但不代表每个账户会在同一时刻到账。它更不能增加额度、绕过限制或主动触发重置。
