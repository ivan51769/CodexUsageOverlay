## 正文

写 Codex 写到一半，<br>
又要去「设置 → 剩余用量」看周用量？<br>
我把常用信息做成了一条跟着 Codex 窗口走的顶部悬浮条。

这次更新又接入了 Tibo Radar 预告：

1、套餐、周用量剩余、重置时间、重置券、累计 Token 和任务状态，一行直接看。

2、有明确预告时，上方会出现独立提醒，显示预计时段、置信度和倒计时。鼠标移到右上角可以临时关闭，单击主条里的重置状态又能打开。

3、支持荧光蓝、磨砂玻璃、渐变橙、渐变粉、渐变彩字 5 种预设主题和自定义背景。改完设置后，运行中的悬浮条会自动更新。

4、可以选择开启 Windows 重置提醒，默认关闭，并按公开原帖编号避免重复通知。

边界也要说清楚：

它只负责显示和提醒，不能增加额度，也不能替你“重置额度”。Tibo Radar 使用公开的非官方状态源，不保证每个账户同时到账；实际用量始终以本机 Codex 返回结果为准。

账户信息只从本机 Codex app-server 读取；不读写 auth.json，也不保存对话正文。Radar 只拉取公开状态，不发送账户令牌或本机用量。

当前版本 1.3.0，适用 Windows 10/11，需要已登录 Codex 桌面端或官方 CLI。项目以 AGPL-3.0 开源，项目名 `CodexUsageOverlay`；安装包以 GitHub 项目页实际内容为准，下载后可核对 SHA-256。

这是非官方辅助工具，与 OpenAI 无隶属或背书关系。
