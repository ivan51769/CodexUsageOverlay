## 最终标题

错过Tibo重置，我像错失一个亿

## 正文

错过一次 Tibo 的重置公告，真的会有种错失一个亿的感觉。

周额度还没用完，第二天才看到消息。明明没有真少一分钱，还是会觉得那些本来能跑掉的任务被自己放过去了。

我还怕另一种情况。重置卡刚用掉，任务还没跑几个，又碰上新的重置窗口。不同账户不保证同时到账，这张卡也未必真能算浪费。可卡换来的额度还没有来得及用，心里就会冒出一句，早知道再等等。

所以我把 Tibo Radar 接进了 Codex 顶部悬浮条。

有明确排期时，顶部会显示预计时段、倒计时和分类置信度。预告窗可以临时关掉，也能从主条重新打开。

我会拿它做两件事。

1、计划窗口已经很近，先把当前额度安排给确定要跑的任务。

2、手里有重置卡又不着急，多看一眼预告再决定什么时候用。

没有明确预告就照常工作。公开信号只能让我早点知道，不能当成到账承诺。

这套工具不直接监控 X。它每 10 分钟读取 Codex Runway 汇总的公开非官方状态。“预告”表示公开帖被分类为明确排期，“今日已重置”表示 Tibo 发过完成公告。你的账号有没有到账，仍然看本机 Codex。

它不能增加额度，也不能主动触发重置。账户与用量由本机 Codex app-server 提供，不读写 auth.json，也不保存对话正文。

v1.3.1 同时修了部分电脑在混合缩放和异常字体下出现的文字空白。程序会提示 GitHub 稳定版更新，右键主用量正文就能退出。

适用 Windows 10 和 Windows 11，项目以 AGPL-3.0 开源。它是非官方辅助工具，与 OpenAI 没有隶属或背书关系。

想试 Windows 版，私信我获取下载链接。
