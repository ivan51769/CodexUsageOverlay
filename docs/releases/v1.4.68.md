# v1.4.68：内存占用优化与有条件后台回收

- 侧栏闲置时减少位置扫描，保留鼠标悬停、滚动及窗口几何变化时的快速更新。
- 自动淘汰已离开当前索引列表的会话缓存，同时保留主日志和续写片段，不删除会话文件。
- 每 30 秒检查助手自身内存；连续两次检测到提交内存至少 256 MiB、与托管堆差额至少 192 MiB，且输入空闲至少 3 秒时，请求后台完整回收。至少间隔 5 分钟，后续须比回收后的采样低点再增长至少 64 MiB 才重试。
- 不裁剪工作集、不清空有效缓存、不关闭 Codex 会话。`memory-recovery.log` 仅保存回收请求或后续采样的数值信息。

验证通过：核心回归、缓存淘汰与续写保留、2 万个 COM 代理回收、侧栏事件和重建恢复、1500 行列表可见区域读取、底部信息条及 100%–200% 缩放。

验证边界：长期内存效果仍需实际运行观察，内存阈值不是占用上限；侧栏改宽的既有回归用例仍可能超时，本版未将其列为修复。

运行附件安装包可覆盖旧版并保留设置，SHA-256 见 `SHA256-v1.4.68.txt`。
