# v1.4.35：会话上下文显示与一键更新

## 本次更新

- 聊天输入框下方增加紧凑上下文状态条，按输入框水平居中；显示当前会话的上下文及输入、缓存复用、输出简写。无数据时明确提示等待，旧记录标明“上次记录”。
- 侧栏会话标题旁显示各自上下文；扩展模式补充已用、剩余、输入、缓存、输出，保留原生任务状态图标位置，滚动时快速跟随。
- 顶部下载按钮右侧增加上下文显示与增强模式快捷开关，支持悬浮反馈并保存选择。
- 兼容新版 Codex 侧栏缩进及文本型标题，修复最大化窗口隐藏边框导致底部一直“等待当前会话数据”的问题。同名会话不猜测匹配，不借用其他会话的数据。
- 绿色“有更新”、更新通知及右键“一键更新”直接下载本助手的正式安装包，校验来源、版本、大小和 SHA256 后覆盖安装并重新启动，保留设置。下载失败不会替换当前版本，可重试。

## 安装

下载 `blues19-CodexUsageUpdateAssistant-Setup-1.4.35.exe`，直接覆盖安装即可。

旧版尚未内置直接更新的，仍需手动安装这一次；从本版起可直接更新至后续正式版。助手自身更新与 Codex 官方 MSIX 下载器是两个独立功能。

## 验证与边界

- 普通窗口、最大化坐标与高 DPI 标题识别回归通过。
- 100%–200% 缩放下的开关、侧栏布局及滚动跟随测试通过。
- 本机最大化窗口运行诊断确认当前会话已匹配、数据可用。
- 正式 Release 安装包下载及 SHA256 校验通过；覆盖安装、重启及单实例检查通过。
- 跨版本一键升级的完整线上流程仍需在后续新版发布时验证。

上下文来自本机 Codex 会话记录；没有有效记录的会话不会伪造数据。诊断仅保存一份本地状态文件，不记录会话正文、标题或凭据。
